# Changelog — V6.3 Final Polish

V6.3 is a refinement release. It deliberately freezes the financial feature set and focuses on consistency, responsiveness and recruiter-facing hierarchy.

## Changes
- Added application-wide responsive layout/CSS guardrails for common laptop widths.
- Standardised page headers across the remaining analytical pages.
- Removed all five-column KPI/control rows from analytical pages.
- Corrected the sidebar model-version/changelog reference.
- Strengthened KPI-card minimum sizing and typography.
- Improved Economic Scenarios KPI hierarchy and shortened technical labels with tooltips.
- Improved Macro Transmission scenario-shock hierarchy.
- Improved Strategic Allocation metric formatting and split dense KPI rows.
- Split Reinsurance treaty controls across two rows.
- Reduced Reinvestment table dominance by moving detailed cash accounts and cross-policy tables into expanders and surfacing headline ALM metrics.
- Added documentation of visual-QA limits: code-level responsive hardening was completed, but browser screenshot validation is still required on a machine with Streamlit/browser runtime.

No new financial module was added.
